Connection Diagram

R
Raspberry Pi
Connected to Arduino via USB, camera via CSI/USB
A
Arduino Connections
D5: IN1, D6: IN2, D9: IN3, D10: IN4 (Motor Driver)
D2: DHT11, A0: Sound Sensor, D3: Impact Sensor
D4: Touch Sensor, D7: Tilt Sensor (HW-505)
D6: PIR Motion Sensor, A1: Rain Drop Sensor
I2C: ADXL345 Accelerometer
J
Joystick Controller
A0: X-axis, A1: Y-axis, D2: Mode Button
Connected to Ubuntu laptop via USB
M
Motor Driver Connections
IN1-IN4: Connected to Arduino
Motor A: Left wheels, Motor B: Right wheels
12V Power: External battery source
P
PIR Motion Sensor
D6: Signal, 5V: Power, GND: Ground
W
Rain Drop Sensor
A1: Signal, 5V: Power, GND: Ground
X
ADXL345 Accelerometer
I2C: SDA (D20), SCL (D21), 3.3V: Power, GND: Ground
